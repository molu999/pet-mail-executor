# 桌宠云端邮件执行器

此仓库只包含运行代码。日程与发送记录保存在用户自己的 Cloudflare D1，邮件账号和执行凭据保存在 GitHub Actions Secrets；仓库不包含任何真实邮件、联系人或凭据。

GitHub Actions 的标准公开仓库运行器当前免费。约每 5 分钟尝试执行一次，平台可能延迟或丢弃定时运行，公开仓库连续 60 天没有活动也可能停用定时工作流。此方案不保证准点、持续可用或永久免费；不会自动购买服务。

手动工作流默认只验证 QQ SMTP TLS/认证、Worker 连接和飞书读取，不领取任务、不发送邮件。必须先完成验证并启用 Worker 的执行开关，才允许领取任务。GitHub 只持有专用执行凭据，不能读取完整任务列表、修改任务或启动飞书授权。

发送前核实飞书最新日程与修改/取消命令，只向明确选择的地址提交邮件。连接中断或结果不确定时不自动重发；结果回传重试不会再次提交 SMTP。已提交邮件服务器不表示已经送达。

桌宠通过私有飞书表格同步。关机前需要看到云端已确认；未确认的修改或取消无法保证生效，已经进入 SMTP 提交的邮件无法撤回。节省免费飞书 API 额度的中转查询间隔为 15 分钟，发送检查与中转确认是不同的时间间隔。

维护所需 Secrets：`PET_CLOUD_URL`、`PET_EXECUTOR_KEY`、`QQ_SMTP_USER`、`QQ_SMTP_AUTH_CODE`。任何凭据都不能写入文件或日志。
